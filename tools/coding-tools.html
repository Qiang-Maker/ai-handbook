AI 编程工具怎么选 ​

AI 编程工具大体分三种形态：终端 Agent、桌面 IDE 和云端生成器。形态决定工作方式，比"哪个更强"更重要。这一篇帮你按自己的场景对号入座。（编程之外的全品类工具——聊天、图像、视频、办公 Agent 等，见《AI 工具全景图》。）

1. 三种形态，三种工作方式 ​

形态代表工作方式适合谁
终端 AgentClaude Code、Codex CLI你在终端描述任务，Agent 自主读代码、改文件、跑命令，多步完成日常写代码、维护真实项目
桌面 IDECursor、Codex 桌面版在图形编辑器里边写边改，AI 建议穿插在编辑流程中喜欢图形界面、想保留完全控制感
云端生成器v0、Bolt、ChatGPT Canvas在网页里描述需求，直接生成可预览的小应用快速原型、非程序员做小工具

三种形态不互斥：很多开发者用终端 Agent 处理主力项目，用云端生成器做小实验。

2. 主力工具逐个看 ​

2.1 Claude Code ​

Anthropic 的终端 Agent，也是目前 Agent 能力的标杆。

  • 强项：长任务自主性好，读整个代码库的能力强，支持 MCP 扩展工具。
  • 形态：终端命令行，可脚本化、可接入 CI，也提供 VS Code 插件。
  • 适合：有终端使用习惯的开发者，接手陌生代码库，大范围重构。
  • 安装教程：Claude Code 全平台安装。

2.2 Codex CLI 与 Codex 桌面版 ​

OpenAI 的编程 Agent，CLI 与桌面双形态。

  • 强项：与 ChatGPT 生态衔接，沙箱执行环境安全，桌面版对新手友好。
  • 适合：ChatGPT 付费用户，想要"开箱即用"桌面体验的人。
  • 安装教程：Codex CLI、Codex 桌面版。

2.3 Cursor ​

基于 VS Code 的 AI IDE，图形界面派的主力选择。

  • 强项：编辑体验流畅，Tab 补全质量高，多文件编辑可视化、逐条确认。
  • 适合：从 VS Code 迁移过来的开发者，喜欢"看着 AI 改每一处"的节奏。
  • 教程：Cursor 使用第三方 AI 接口。

2.4 CC Switch ​

严格说不是编程工具，而是供应商切换器：在多个 API 供应商（包括 STJAPI）之间一键切换 Claude Code / Codex 的配置。

  • 适合：已经用上 Agent 工具、需要在多个供应商间管理配置和排障的人。
  • 教程：CC Switch 对接 STJAPI。

3. 按场景推荐 ​

你的情况建议起点
资深开发者，日常维护真实项目Claude Code 或 Codex CLI，终端 Agent 收益最大
用 VS Code 多年，不想换工作流Cursor，或 Claude Code 的 VS Code 插件
刚入门编程 / 非程序员Codex 桌面版或云端生成器，图形界面降低门槛
接手陌生大型代码库，需要快速摸底终端 Agent：让它先读代码库、画架构、列疑点
需要在多个 API 供应商间切换任选主力工具 + CC Switch 管理配置

4. 决定收益的不是工具，是用法 ​

  1. 任务粒度给对：Agent 工具适合"完成 X 这个目标"，IDE 补全适合"改这一段"。拿 Agent 干碎片小事，或拿补全干大重构，都会失望。
  2. 先让它读，再让它改：陌生项目先让 Agent 分析现状、提出方案，确认后再动手，成功率显著更高。
  3. 配置稳定是体验的一半：Agent 工具重度依赖 API 连接质量。接口不稳定时，任何工具都"变笨"。建议按《STJAPI 账户与网络设置》把接入环境理顺，再评价工具本身。
  4. 每周复盘一次工作流：AI 编程工具迭代极快，定期检查"哪些步骤我还在手工做，AI 能不能接手"，比追逐新工具有用。

选好了工具，就去《接入实战》板块把它跑起来；用起来之后，按《从零到驾驭 AI：成长路径》第四阶段把协作习惯养对。
