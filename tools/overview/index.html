AI 工具全景图 ​

AI 工具已经渗透到几乎所有工作场景。这一篇给你一张完整的地图：每类工具解决什么问题、代表产品有哪些、各自强在哪、怎么选。编程类工具在本手册有专门教程，这里做索引式展开。

1. 聊天助手：万能起点 ​

1.1 解决什么 ​

问答、写作、翻译、头脑风暴、分析文档、日常决策参考。几乎所有 AI 使用的起点，也是各类工具能力最重叠、最不值得同时用多个的品类。

1.2 代表产品 ​

产品出品方特点
ChatGPTOpenAI生态最大，多模态能力齐全，插件与自定义 GPT 丰富
ClaudeAnthropic长文分析与写作质量出色，编程与 Agent 能力强
GeminiGoogle与搜索、Gmail、Docs 生态结合紧密，长上下文窗口大
DeepSeek深度求索推理能力强，开源模型可自部署，API 价格低
Kimi月之暗面长文本处理见长，中文资料分析体验好
通义千问阿里巴巴与阿里生态整合，开源 Qwen 系列覆盖全尺寸
豆包字节跳动移动端体验好，语音对话自然，免费额度大方
GrokxAI与 X（Twitter）实时信息结合，风格直接
Mistral / Llama开源阵营可本地部署、可商用定制，适合隐私敏感场景

1.3 怎么选 ​

主力一个（付费）、备用一个（免费）即可。选择看三点：你所在生态（Google 系选 Gemini、微软系选 Copilot/ChatGPT）、中文质量（国产模型普遍更好）、是否需要 API（见《接入实战》）。频繁切换的收益远低于熟悉一个的成本。

2. AI 编程：从补全到 Agent ​

2.1 解决什么 ​

写代码、改 bug、重构、理解陌生代码库、批量修改。这是当前 AI 落地最深、收益最高的领域，工具形态也分化最明显。

2.2 终端 Agent ​

在本地项目里自主完成多步任务：搜索代码、规划方案、编辑文件、运行验证。

工具特点
Claude CodeAgent 能力标杆，Plan 模式、Hooks、子代理、MCP 生态齐全
Codex CLIOpenAI 出品，与 ChatGPT 账号体系打通，轻量直接
Gemini CLIGoogle 出品，免费额度较大，与 Gemini 生态联动
Aider开源命令行结对编程，git 集成细致，可接任意模型
OpenCode / Crush开源终端 Agent，模型可自由切换

2.3 IDE 与编辑器 ​

边写边让 AI 改，图形界面友好，适合喜欢可视化交互的开发者。

工具特点
Cursor基于 VS Code 的 AI 编辑器，Composer 多文件改写体验好
WindsurfCascade Agent 流程引导细致，上手平缓
VS Code + Copilot微软官方，补全稳定，企业采用率最高
JetBrains AI与 IntelliJ 系 IDE 深度整合，Java/Kotlin 体验好
Qoder（原通义灵码）阿里云出品，Java 与阿里云生态适配深，支持企业私有化部署
智谱 ZCode自研 Agent 内核 + GLM 系模型，支持 MCP 协议，适合国产化环境
Trae字节出品，国内可直连，免费额度多
Zed高性能编辑器，AI 能力原生集成，启动快

2.4 网页与云端构建 ​

无需本地环境，从描述直接生成应用或原型。

工具特点
v0Vercel 出品，React/Next.js 组件生成质量高
Bolt.new全栈应用生成，浏览器内直接运行
Lovable面向非程序员，从想法到可部署应用
Replit云端 IDE + Agent，从编写到托管一站式

2.5 怎么选 ​

开发者优先终端 Agent（可脚本化、可自动化、上下文利用最充分）；重图形界面选 Cursor 或 Windsurf；非程序员做小工具，从 Lovable、Bolt 开始。详细对比见《AI 编程工具怎么选》，Claude Code 的进阶用法见《Claude Code 进阶玩法》。

3. 图像生成 ​

3.1 解决什么 ​

插画、海报、产品图、概念设计、风格探索、配图量产。

3.2 代表产品 ​

工具特点
Midjourney审美与艺术效果最好，社区提示词生态丰富，仅网页/Discord 使用
GPT-4o / DALL·E在 ChatGPT 内直接用，指令理解强，图中文字准确度高
Nano Banana（Gemini）图像编辑与多图融合强，对话式改图自然
Flux开源阵营画质标杆，可本地部署可微调
Stable Diffusion + ComfyUI可控性最强，节点式工作流，可训练专属风格，门槛最高
Ideogram图内文字渲染最好，做海报和 Logo 草案实用
即梦 / 通义万相国内可直接访问，中文指令友好，免费额度可用

3.3 怎么选 ​

偶尔出图用聊天助手内置生图即可；对画面质量与风格有要求上 Midjourney；需要批量、可复现的生产管线再投入 ComfyUI。图内含文字的需求优先试 GPT-4o 或 Ideogram。

4. 视频生成 ​

4.1 解决什么 ​

文生视频、图生视频、片段素材、口播内容。目前所有工具都适合做片段与素材，完整叙事长片尚不成熟。

4.2 代表产品 ​

工具特点
SoraOpenAI 出品，物理一致性与创意运镜强
VeoGoogle 出品，音画同步生成是亮点
可灵（Kling）快手出品，国内可用，动作幅度与时长表现好
即梦字节出品，与剪映工作流衔接顺滑
Runway老牌创作工具，特效与控制工具链丰富
Pika轻量趣味风格，上手快

4.3 数字人与口播 ​

把文案变成真人出镜视频，做内容营销效率极高：HeyGen（口型与音色克隆自然）、剪映数字人（国内最易得）、Synthesia（企业培训场景成熟）。

4.4 怎么选 ​

国内直接可用的选可灵、即梦；做营销口播直接上 HeyGen 或剪映；视频生成目前按秒计费普遍不便宜，先小成本试效果再放量。

5. 语音与音频 ​

5.1 解决什么 ​

配音、转写、播客、音乐创作、实时翻译。

5.2 代表产品 ​

场景工具特点
文字转语音（TTS）ElevenLabs情感与多语种表现标杆，可克隆音色
文字转语音（TTS）MiniMax Audio、火山引擎中文自然度高，价格低
语音转文字（ASR）Whisper开源标准，本地可跑，多语言
会议转写飞书妙记、通义听悟转写+摘要+说话人分离，日常最实用
音乐生成Suno从歌词到成曲一键生成，质量和长度领先
音乐生成Udio风格控制细致，适合小样创作

5.3 怎么选 ​

转写和会议纪要是当下实用度最高的语音工具，几乎零门槛；配音需求 ElevenLabs（英文）或 MiniMax（中文）；音乐创作 Suno 足够入门。

6. AI 搜索 ​

6.1 解决什么 ​

把"翻十篇文章找答案"变成"直接得到带引用的答案"。

6.2 代表产品 ​

工具特点
PerplexityAI 搜索代表，答案带来源引用，学术模式可筛论文
ChatGPT / Gemini 内置搜索聊天与搜索合一，日常够用
秘塔 AI 搜索国内可用，大纲式结果组织，中文来源丰富
纳米 AI 搜索360 出品，多模型聚合回答

6.3 怎么选 ​

查资料优先用带引用的 AI 搜索，方便溯源验证；重要结论一定点开原始来源确认——AI 搜索也会引用错误或不存在的页面。

7. 知识管理与研究 ​

7.1 解决什么 ​

把散落的资料变成可问答、可引用、可生产的个人知识库。

7.2 代表产品 ​

工具特点
NotebookLMGoogle 出品，基于你上传的文档回答，带引用，可生成摘要音频
Notion AI笔记内直接问答与写作，团队知识库场景强
Obsidian + AI 插件本地 Markdown 库 + 可换模型的问答插件，隐私可控
飞书智能伙伴与飞书文档、多维表格联动，国内企业协作顺

7.3 怎么选 ​

读论文、啃报告用 NotebookLM；个人笔记体系在 Obsidian 或 Notion 里就地接入 AI；核心原则是让 AI 基于你的资料回答，而不是凭模型记忆瞎编。

8. 办公与创作效率 ​

8.1 办公 Agent：新一代主力 ​

2026 年办公工具的主线是"说需求、交结果"的 Agent 形态——不是在对话框里给建议，而是直接操作文档、表格和本地文件完成任务。

工具特点
WorkBuddy腾讯出品的 AI 办公 Agent，调研、文档撰写、数据分析一体交付，桌面端可操作本地文件，支持多 Agent 并行；免费体验版，标准版 ¥70/月起
Kimi Work月之暗面出品，长文档批量处理强，可挂载本地文件夹读写，投研咨询场景好用
阶跃 AI 桌面版全场景办公 Agent，扫码即用免配置，自研模型针对任务执行训练
办公小浣熊商汤出品，数据分析与报表专精，支持 20 多种办公格式解析
QClaw腾讯电脑管家出品，微信扫码直连、手机遥控电脑，本地执行数据不上传

8.2 文档、表格与演示 ​

场景工具特点
演示文稿Gamma、SlidesAI从大纲一键生成成品 PPT，排版质量高
演示文稿WPS AI、Kimi PPT国内可用，中文模板全
表格分析ChatGPT / Gemini 数据分析上传 CSV 直接分析出图
协作文档腾讯文档 AI、Notion AI、Coda AI在写作场景内就地问答、润色、总结
可视化协作Miro AI白板内生成与整理思路，团队头脑风暴顺

8.3 会议与沟通 ​

场景工具特点
会议纪要Fireflies、tl;dv、Fathom自动入会记录、转写、摘要，按说话人整理待办
会议纪要（国内）飞书妙记、腾讯会议 AI国内会议生态直接可用
邮件沟通各邮箱内置 AIGmail、Outlook 的回复建议已足够日常

8.4 怎么选 ​

办公 Agent 正在快速迭代，WorkBuddy、Kimi Work 这类"桌面执行型"是当前的主航道，选一个用熟即可。这一类工具替代的是"格式劳动"而非"思考劳动"，生成结果（尤其是数据和结论）必须自己过一遍再交付。

9. Agent 与自动化平台 ​

9.1 解决什么 ​

把 AI 从"一问一答"变成"自动完成多步任务"：定时监控、跨应用流转、批量处理。面向普通用户的桌面办公 Agent 已在上一节展开，这里覆盖搭建、开发与企业侧。

9.2 搭建平台（低代码） ​

自己动手编排 Agent 应用，不写代码或少量代码。

工具特点
扣子（Coze）字节出品，零代码搭 Bot，一键发布到微信、飞书、抖音，3.0 支持多 Agent 协作
Dify开源可私有化，数据自主可控，模型接入不受限，工作流编排能力全
百度千帆 AppBuilderRAG 与知识库能力强，教育、法律、政务行业模板多
FastGPT开源知识库问答专精，分段策略可视化调试
n8n开源自动化编排，AI 节点丰富，可自部署
Zapier + AI海量应用连接器，适合海外 SaaS 流程

9.3 开发者框架 ​

构建自定义 Agent 系统的底层基础设施。

工具特点
OpenClaw开源桌面 Agent 框架，社区技能生态大，国产模型适配好
LangGraph图状态机架构，生产成熟度高，适合复杂有状态工作流
CrewAI多智能体协作设计直观，角色化上手快，适合原型验证

9.4 企业级平台 ​

工具特点
实在 Agent屏幕语义理解不依赖 API，可操作无接口的老系统，信创适配全
飞书 Aily飞书原生集成，员工零安装，多 Agent 组队
阿里云百炼多模型调度，MCP 连接数据库/CRM/ERP，按量付费
腾讯云 ADP智能体编排 + 知识库 + 工作流一站式，衔接企业微信生态

9.5 云端挂机与 RPA ​

工具特点
JVS Claw阿里云出品，云端沙箱关机也能跑，适合 7×24 定时任务
天工 Skywork常驻云端，Agent 可进飞书、钉钉群协作
影刀 RPA个人社区版免费，低代码搭流程，适合固定规则的重复操作
来也科技企业级 RPA 老牌，政务金融积累深，正向智能体流程自动化演进

9.6 怎么选 ​

个人自动化从扣子或 n8n 起步；重视数据主权选 Dify 自部署；企业老系统自动化看实在 Agent；固定流程的重复点击用影刀。注意区分两类工具：Agent 是"大脑"（理解目标、自主规划），RPA 是"手脚"（按固定流程模拟操作），选型路径不同。Agent 类工具的执行结果必须有人工确认环节，尤其是涉及发消息、支付等不可逆操作。

10. 本地部署与开源生态 ​

10.1 解决什么 ​

隐私敏感数据不出本机、无网络环境使用、深度定制模型行为。

10.2 代表工具 ​

工具特点
Ollama一条命令拉起本地模型，生态最普及
LM Studio图形界面管理本地模型，新手友好
Open WebUI给本地模型套上 ChatGPT 式网页界面

常用开源模型：Llama（Meta）、Qwen（阿里，全尺寸覆盖）、DeepSeek（推理强）、Gemma（Google 轻量）。7B 级模型 16GB 内存可跑，追求质量选 32B 以上并确认显存充足。

10.3 怎么选 ​

先问自己是否真的需要本地部署：没有强隐私要求，云端 API 更省心。确有需要，从 Ollama + Qwen 7B 起步体验，再决定投入硬件。

11. 一条选型主线 ​

工具会不断更替，选型逻辑始终是同一条：

  1. 先明确任务：同一任务选一个顺手的，用熟比换新收益大。
  2. 从免费额度开始：确认真的高频使用，再付费。
  3. 警惕工具债：每个新工具都有学习成本，"收藏了等于会了"是错觉。
  4. 能力分层看：模型决定上限，产品形态决定效率，接入质量决定稳定性——三层分开评估。
  5. 接入方式要顺：需要 API 的场景（自用客户端对接、批量调用），关注平台的稳定性与文档质量，这也是本手册《接入实战》板块存在的意义。
