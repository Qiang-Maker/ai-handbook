CC Switch 对接 STJAPI ​

CC Switch 用于管理 Claude、Codex、Gemini 等客户端的服务配置。本页以 STJAPI 为例，说明下载、基础设置和令牌导入流程。

1. 准备工作 ​

1.1 安装 Claude Code ​

请先完成 Claude Code 全平台安装。CC Switch 用于管理配置，CLI 本体仍需要独立安装。

1.2 准备 STJAPI 令牌 ​

登录 STJAPI 控制台，创建令牌时确认分组无误。令牌创建后可直接导入 CC Switch。

2. 下载 CC Switch ​

从 CC Switch Releases 下载对应系统版本。

  • Windows：先点击 Show all assets 展开完整列表，再选择 MSI 安装包。
  • macOS、Linux：选择和处理器架构相符的安装包。
  • 列表中通常同时有绿色便携版和安装程序；日常使用推荐安装程序。

3. 设置 CC Switch ​

3.1 打开设置 ​

启动 CC Switch 后，点击左上角的设置图标。

3.2 通用选项 ​

在通用选项中下拉查看开关。按当前客户端和使用习惯启用推荐选项，保存后再进行供应商配置。

3.3 高级选项 ​

高级选项中需要设置本机 Claude 相关配置文件夹。使用默认路径时先确认它指向当前正在使用的 Claude 配置目录。

4. 添加 STJAPI 供应商 ​

4.1 从控制台导入 ​

回到 STJAPI 的令牌列表，点击目标令牌旁的“导入到 CCS”。CC Switch 中出现新增配置后，检查服务地址、令牌名称、分组和启用状态；如果列表中已有同名配置，优先更新已有项，避免误用旧令牌。

4.2 Codex 使用 GPT 模型时 ​

当 Codex 使用 GPT 模型时，不需要开启路由。保存配置后，在 CC Switch 中选择对应供应商并启用。

5. 验证连接 ​

  1. 在 CC Switch 中启用刚导入的配置。
  2. 打开终端，执行 claude 或 codex。
  3. 发送一个简单任务，例如“解释当前目录的文件结构”。
  4. 在 STJAPI 控制台确认令牌出现使用记录。

连接失败时按以下顺序检查：

  1. STJAPI 账户与网络设置 中的网络和直连规则。
  2. CC Switch 当前启用的配置，确认不是同名旧配置。
  3. 令牌分组、服务地址和模型是否匹配。
  4. STJAPI 控制台是否有新的使用记录。
