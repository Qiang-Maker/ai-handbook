Claude Code 全平台安装 ​

本页优先使用官方原生安装器；只有原生安装器不可用、需要固定版本或已有 npm 工作流时，才使用包管理器或 npm。

1. 官方原生安装器 ​

1.1 macOS、Linux 与 WSL ​

在终端中运行：

bash
curl -fsSL https://claude.ai/install.sh | bash

安装结束后关闭当前终端，重新打开一个窗口。

1.2 Windows PowerShell ​

以普通用户身份打开 PowerShell，不需要管理员权限：

powershell
irm https://claude.ai/install.ps1 | iex

1.3 Windows CMD ​

在命令提示符中运行：

text
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

PowerShell 不支持这条 CMD 命令中的 && 分隔符；CMD 也不识别 irm。请确认终端类型后复制对应命令。

2. 验证与首次登录 ​

2.1 验证安装 ​

bash
claude --version
claude doctor

能看到版本号说明命令已经可用。claude doctor 会检查 PATH、认证、网络和更新状态，安装异常时优先运行它。

2.2 首次登录 ​

进入一个项目目录后运行：

bash
claude

命令会打开浏览器并引导登录。没有浏览器的环境可通过环境变量提供 API Key：

bash
export ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
claude

Windows PowerShell 使用下面的写法，关闭窗口后环境变量不会继续保留：

powershell
$env:ANTHROPIC_API_KEY = "sk-ant-xxxxxxxx"
claude

API Key 登录和浏览器登录选择其一即可；使用 STJAPI 令牌时，按 CC Switch 对接 STJAPI 完成供应商配置。不要把真实 API Key 或令牌写入项目文件，也不要提交到仓库。

3. 平台补充安装方式 ​

3.1 macOS Homebrew ​

bash
brew install --cask claude-code
brew upgrade claude-code

Homebrew 版本不会自动更新，需要按需执行升级命令。

3.2 Windows WSL 与 WinGet ​

需要 Linux 工具链或沙箱时，在管理员 PowerShell 中先安装 WSL：

powershell
wsl --install -d Ubuntu

打开 Ubuntu 后，按 macOS、Linux 的原生安装器步骤安装。习惯使用 WinGet 时也可以运行：

powershell
winget install Anthropic.ClaudeCode

3.3 Linux 系统包管理器 ​

Debian、Ubuntu、Fedora、RHEL 和 Alpine 的官方仓库配置会随发行版变化。服务器环境优先查看 Claude Code 官方安装文档，按当前发行版执行对应命令。

4. npm 备用安装 ​

只有原生安装器无法使用、需要固定版本或必须接入 npm 工作流时，才使用 npm。需要 Node.js 18 或更高版本：

bash
node -v
npm install -g @anthropic-ai/claude-code

升级时：

bash
npm install -g @anthropic-ai/claude-code@latest

不要使用 sudo npm install -g，这会使后续权限问题更难排查。

5. fnm 与 npm 镜像 ​

没有 Node.js 或 npm 全局目录报权限错误时，可用 fnm 管理用户级 Node.js：

bash
curl -fsSL https://fnm.vercel.app/install | bash
fnm install --lts
fnm use lts-latest
fnm default lts-latest

如果 npm 下载缓慢，设置镜像后再安装：

bash
npm config set registry https://registry.npmmirror.com
npm install -g @anthropic-ai/claude-code

恢复官方源：

bash
npm config set registry https://registry.npmjs.org

6. 使用 STJAPI ​

使用多供应商、账号切换或中转服务时，先安装 Claude Code，再按 CC Switch 对接 STJAPI 导入从 STJAPI 控制台创建的令牌。完成后在项目目录执行 claude 做一次简单验证。

验证时建议先使用低成本、短上下文的请求；确认响应正常后，再开始长对话或批量任务。

7. 常见问题 ​

7.1 claude: command not found ​

关闭终端并重新打开；仍未解决时运行 claude doctor。npm 安装则检查 npm config get prefix 返回目录是否已加入 PATH。

7.2 npm 权限错误 ​

避免使用 sudo 安装。按第 5 节用 fnm 安装 Node.js 后，再在普通用户终端执行 npm 安装。

7.3 安装或登录网络异常 ​

先确认目标站点可以访问，并遵循 STJAPI 账户与网络设置 中的直连检查。公司网络有 TLS 拦截时，需由网络管理员提供对应 CA 证书。
