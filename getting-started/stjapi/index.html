STJAPI 账户与网络设置 ​

1. 进入 STJAPI ​

访问 STJAPI 控制台 注册或登录账户。完成登录后，可以在控制台创建令牌、选择分组并查看使用情况。

2. 创建使用令牌 ​

令牌是客户端访问 STJAPI 的凭据。建议为不同客户端或用途分别创建令牌，后续出现异常时更容易定位和撤销。

2.1 选择正确分组 ​

创建令牌时，先选择和当前客户端、模型用途相符的分组。令牌创建完成后请立即保存，仅在受信任的客户端或环境变量中使用，不要把完整令牌贴到聊天记录、截图或代码仓库中。

2.2 导入到支持的客户端 ​

CC Switch 可以直接从控制台导入令牌；其他客户端则按对应教程填写服务地址、令牌和模型。服务地址优先使用控制台或客户端接入页显示的值，不要自行拼接路径。完成导入后，先发送一个简单请求验证连接。

3. 连接异常 ​

3.1 不需要额外网络环境 ​

STJAPI 在国内外环境都可直接访问。连接失败时，先关闭不必要的特殊网络环境并重新加载网站；部分代理规则会把站点路由到不正确的出口，表现为连接超时。

3.2 将站点加入直连规则 ​

如果必须使用代理软件，请将 ai.stjapi.com 加入直连规则。以下是 mihomo 覆写脚本示例：

javascript
// https://mihomo.party/docs/guide/override/javascript
const prependRule = [
  'DOMAIN-SUFFIX,ai.stjapi.com,DIRECT'
]

function main(config) {
  const oldRules = config.rules
  config.rules = prependRule.concat(oldRules)
  return config
}

在客户端的订阅或覆写配置中加入规则后，保存并刷新配置。

4. 完成前检查 ​

  1. 可以正常打开 ai.stjapi.com。
  2. 已创建令牌并选择正确分组。
  3. 客户端中的服务地址和令牌已保存。
  4. 用一条简单请求确认模型响应正常。

如果只是想确认令牌是否生效，优先在客户端发送一句短请求，不要直接运行大批量任务。这样可以同时检查网络、分组、模型和用量记录。

下一步可按正在使用的工具进入 Claude Code、Codex CLI、Codex 桌面版、CC Switch 或 Cursor 教程。第一次接入想跟着完整练习走的，看《从零到驾驭 AI：成长路径》第三阶段。
